# SlideSAVE: IoT-based Landslide Detection Mobile Application and Automated Barricade System

## Overview
SlideSAVE is an IoT-based mobile application developed to provide early warning notifications for landslide risks. The system integrates sensor monitoring, Firebase Realtime Database, and an Android mobile application.

## Features
- User authentication
- Real-time sensor data monitoring
- Landslide alert notification
- Emergency contact management
- Automated barricade notification

## Technologies Used
- Java
- Android Studio
- Firebase Realtime Database
- Firebase Authentication
- Room Database

## Project Role
Developed the Android mobile application, designed database structure, integrated Firebase services, and conducted system testing.
