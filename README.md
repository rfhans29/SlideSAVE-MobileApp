# SlideSAVE: IoT-based Landslide Detection Mobile Application and Automated Barricade System

## Overview

**SlideSAVE** is an IoT-based mobile application developed to provide early warning notifications for potential landslide risks.

The system integrates **IoT sensor monitoring, Firebase Realtime Database, and an Android mobile application** to allow users to monitor environmental conditions and receive landslide alerts.

## Features

* 🔐 User authentication
* 📡 Real-time sensor data monitoring
* 🚨 Landslide risk alert notifications
* 📞 Emergency contact management
* 🛑 Automated barricade system notifications
* ☁️ Real-time data synchronization using Firebase

## Technologies Used

| Technology                 | Purpose                                    |
| -------------------------- | ------------------------------------------ |
| Java                       | Android application development            |
| Android Studio             | Mobile application development             |
| Firebase Realtime Database | Real-time sensor data and application data |
| Firebase Authentication    | User authentication                        |
| Room Database              | Local storage for emergency contacts       |

## Project Role

I was responsible for developing and integrating the Android mobile application, including:

* Designing and implementing the mobile application interface
* Developing application features using **Java and Android Studio**
* Integrating **Firebase Authentication**
* Integrating **Firebase Realtime Database** for real-time data monitoring
* Designing the database structure
* Implementing emergency contact management using **Room Database**
* Conducting system testing and troubleshooting
* Ensuring the application provides clear and accessible landslide alerts
